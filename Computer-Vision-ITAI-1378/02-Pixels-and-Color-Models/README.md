# Pixels and Color Models

## Problem Statement

This assignment explains how computers represent colorful images as numerical pixel grids and how different color models describe the same visual information.

## Approach

The reflection describes pixel coordinates, RGB additive color, and HSV components. A visual-storytelling approach centered on a color-changing panda was used to make channel manipulation and color mathematics easier to explain.

## Results

The completed reflection connects pixel values and color channels to visible changes in an image, using a narrative example to make the technical ideas easier to follow.

## Key Findings

- A digital image is a grid in which each position stores numerical color information.
- RGB is designed around emitted red, green, and blue light.
- HSV separates hue, saturation, and brightness-like value in a way that is often easier for people to reason about.
- Storytelling can make technical visual concepts more accessible.

## Technologies Used

Digital-image fundamentals, RGB and HSV color models, visual communication, and technical writing.

## Data

This is a written reflection. It does not train a model or use a dataset.
