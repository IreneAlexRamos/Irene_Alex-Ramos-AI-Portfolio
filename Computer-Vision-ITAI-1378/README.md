# Computer Vision and AI — ITAI 1378

This course portfolio follows my progression from image fundamentals to modern computer vision models. It includes all completed assignments supplied for the portfolio, with descriptive file names, original notebook outputs, written reflections, and documentation for each project.

## Course Topics

- Pixels, image matrices, RGB/HSV color models, and grayscale conversion
- Point, neighborhood, histogram, and geometric image operations
- HOG and LBP feature extraction
- SVM and Random Forest classification
- Neural networks and convolutional neural networks with PyTorch
- YOLO11 object detection, instance segmentation, and SAM 2
- Model evaluation, overfitting, bias, privacy, and safe deployment
