# GitHub and Colab Foundations

## Problem Statement

How can a simple notebook demonstrate the basic workflow used throughout the course: combining explanation, executable Python, saved output, and version control?

## Approach

I created a Jupyter notebook with a Markdown introduction and a Python code cell, ran the cell, preserved its output, and published the notebook through GitHub.

## Results

The code cell ran successfully and saved the output `Hello, World!` in the notebook.

## Key Findings

- Markdown cells explain the purpose of code instead of leaving it without context.
- Saved outputs make a notebook reviewable even before it is rerun.
- GitHub provides a readable history and public home for notebook work.

## Technologies Used

Python, Jupyter Notebook, Google Colab, Git, GitHub, and Markdown.

## Data

No dataset is required for this introductory exercise.
