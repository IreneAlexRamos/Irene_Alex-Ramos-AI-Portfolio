# GitHub and Colab Foundations

## Overview

This introductory exercise demonstrates the basic workflow used throughout the course: create a Jupyter notebook, combine Markdown with executable Python, and manage the file with Git and GitHub.

## Skills Demonstrated

- Creating Markdown and code cells in a notebook
- Running Python interactively
- Saving an `.ipynb` file with its output
- Using GitHub as a public project repository

## Artifact

- [My-First-Notebook.ipynb](My-First-Notebook.ipynb)
- [Original practice repository](https://github.com/IreneAlexRamos/jupyter-exploration)

## How to Run

Open the notebook in Jupyter or Google Colab and run its Python cell. It has no external dependencies or dataset.
